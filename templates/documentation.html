Documentation

Please check the API documentation here or here to properly use the API.

The current API endpoints are:

  • 48 hours weather forecast in a demonstration site from GFS: GET /view/gfs/{site}
  • 48 hours weather forecast in a demonstration site from GFS: GET /api/gfs/{site}/{field}
  • Sentinel2 datasets availability: GET /api/sentinel2_avail/{site}
  • Sentinel2: GET /api/sentinel2/{site} - with date parameter: GET /api/sentinel2/{site}?date=YYYYMMDD
  • Sentinel2 Ussana/Benatzu test-case historical NDVI: GET /view/sentinel2_ndvi_fields/{site}
  • List of parameter names of the digital twin for the campaign year: GET /api/digital_twin_keys/{year}
  • Get time series for a parameter (must be in the list of available parameters): GET /api/digital_twin_values/{year}/{param}
